# Changelog

## [0.1.0] - 2026-02-05

### Added
- Initial release of Burrp
- Local AI processing using Ollama models (default: gemma3)
- Extension-based file categorization
- Dry-run mode for previewing changes
- Undo functionality for last 5 operations
- Configuration file support (~/.config/burrp/config.json)
- CLI with multiple options (model, dry-run, verbose, undo, config)
- Auto-creation of configuration files
- Filename collision handling with counter suffix
- Empty folder cleanup after undo
- Verbose logging mode
- Setup.py for pip installation
- Unit tests
